# LLM Routing Setup

Öffentliche, secret-freie Betriebsdokumentation für das Geräte- und Agentensystem aus MacBook und Mac mini, einschließlich:

`Claude Code → Claude Code Router (CCR) → OmniRoute → Provider/Modelle`

sowie Codex Remote/CLI, Hermes Agent, Profile, lokale Modelle und die zugehörigen Netzwerkgrenzen.

Die veröffentlichte GitHub-Pages-Seite ist der primäre Einstieg. Alle Markdown-Seiten werden über Jekyll gebaut; Mermaid-Diagramme werden clientseitig gerendert.
